# brand-identity

A Claude Code skill that designs a complete brand identity: logo, colors, typography, voice, and real AI product mockups, delivered as a brand guideline deck (PDF). English and Arabic.

Try it online first: **[brand.sadaorg.com](https://brand.sadaorg.com)**

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/AbdulkareemKR/brand-identity-generator/main/install.sh | bash
```

## Use

In [Claude Code](https://claude.com/claude-code), say:

```
create a brand identity for my coffee shop "terra"
```

Add `OPENAI_API_KEY` to your env for AI mockups. Works without it too.
